# Kind

# Scope

STAFF_API_URL=http://localhost:3040
# [per store] [per environment] This storefront's public origin, https in production (loopback

SITE_URL=http://localhost:3030
# [per store] [pair: backend STORE_ID] This deployment's store id: a lowercase slug (a-z, 0-9, hyphens; 1-40

# backend that answers as a different store. Boot refuses to start without it. Not a secret. Only boot requires it:
# a production build without it still succeeds (catalog reads degrade to their absent state).
